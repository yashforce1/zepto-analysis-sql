# 🗄️ Database Schema

The following table was created to store the Zepto product data:

```sql
CREATE TABLE zepto(
    sku_id SERIAL PRIMARY KEY,
    category VARCHAR(120),
    name VARCHAR(150) NOT NULL,
    mrp NUMERIC(8,2),
    discount NUMERIC(8,2),
    availableQuantity INTEGER,
    discountedSellingPrice NUMERIC(8,2),
    weightInGms INTEGER,
    quantity INTEGER
);
```

### Important Columns

| Column | Description |
|---|---|
| `sku_id` | Unique identifier for each product entry |
| `category` | Product category |
| `name` | Product name |
| `mrp` | Maximum Retail Price |
| `discount` | Discount value |
| `availableQuantity` | Available stock quantity |
| `discountedSellingPrice` | Product selling price after discount |
| `weightInGms` | Product weight in grams |
| `quantity` | Product quantity |

# 🧹 Data Cleaning

Several data-cleaning operations were performed before starting the analysis.

## 1. Identifying Invalid Prices

Products having zero MRP or selling price were identified.

```sql
SELECT *
FROM zepto
WHERE mrp = 0
   OR discountedSellingPrice = 0;
```

Products with invalid MRP values were removed.

```sql
DELETE FROM zepto
WHERE mrp = 0;
```

---

## 2. Correcting Product Prices

The original price values were stored in paise-like format.

For example:

```text
2000 → ₹20.00
```

The prices were therefore converted to their correct format.

```sql
UPDATE zepto
SET mrp = mrp / 100,
    discountedSellingPrice = discountedSellingPrice / 100;
```

---

## 3. Checking Product Categories

```sql
SELECT DISTINCT category
FROM zepto
ORDER BY category;
```

This query identifies all unique product categories available in the dataset.

---

## 4. Finding Repeated Products

```sql
SELECT
    name,
    COUNT(sku_id) AS number_sku
FROM zepto
GROUP BY name
HAVING COUNT(sku_id) >= 5
ORDER BY COUNT(sku_id) DESC;
```

This analysis helps identify products that appear multiple times with different SKUs or variants.

# 📊 Business Analysis

After cleaning the data, several business-related questions were answered using SQL.

---

## 1. Top 10 Products with the Highest Discount Percentage

The discount percentage was calculated using:

```text
(MRP - Selling Price)
--------------------- × 100
        MRP
```

SQL:

```sql
SELECT DISTINCT
    name,
    mrp,
    ROUND(
        ((mrp - discountedSellingPrice) / mrp) * 100,
        2
    ) AS discount_percent
FROM zepto
ORDER BY discount_percent DESC
LIMIT 10;
```

### Business Insight

This analysis helps identify products offering the largest percentage discounts to customers.

---

## 2. Estimated Revenue by Product Category

```sql
SELECT
    category,
    SUM(discountedSellingPrice * availableQuantity) AS total_revenue,
    COUNT(*) AS no_of_items
FROM zepto
GROUP BY category
ORDER BY total_revenue DESC;
```

### Business Insight

This query estimates the potential inventory revenue generated by each product category based on:

```text
Selling Price × Available Quantity
```

It can help identify categories with the highest potential sales value.

---

## 3. Expensive Products with Low Discounts

```sql
SELECT DISTINCT
    name,
    mrp,
    ROUND(
        ((mrp - discountedSellingPrice) / mrp) * 100,
        2
    ) AS discount_percent
FROM zepto
WHERE mrp > 500
  AND ((mrp - discountedSellingPrice) / mrp) * 100 < 10
ORDER BY discount_percent DESC;
```

### Business Insight

This query identifies higher-priced products that provide relatively small discounts.

Such products may be useful when studying pricing strategies and premium product segments.

---

## 4. Top 5 Categories with the Highest Average Discount

```sql
SELECT
    category,
    ROUND(
        AVG(
            ((mrp - discountedSellingPrice) / mrp) * 100.0
        ),
        2
    ) AS avg_discount_percent
FROM zepto
GROUP BY category
ORDER BY avg_discount_percent DESC
LIMIT 5;
```

### Business Insight

This analysis identifies the categories where customers receive the highest average discounts.

---

## 5. Price per Gram Analysis

To compare differently sized products fairly, the selling price per gram was calculated.

```sql
SELECT DISTINCT
    name,
    weightInGms,
    discountedSellingPrice,
    ROUND(
        discountedSellingPrice / weightInGms,
        2
    ) AS price_per_gram
FROM zepto
WHERE weightInGms > 100
ORDER BY price_per_gram;
```

### Business Insight

This query helps identify products that provide the best value based on weight rather than simply comparing their selling prices.

---

## 6. Product Classification Based on Weight

Products were grouped into three different weight categories.

```sql
SELECT DISTINCT
    name,
    weightInGms,
    CASE
        WHEN weightInGms <= 500 THEN 'Low'
        WHEN weightInGms < 2500 THEN 'Medium'
        ELSE 'High'
    END AS weight_category
FROM zepto;
```

### Weight Classification

| Weight | Category |
|---|---|
| ≤ 500g | Low |
| 501g – 2499g | Medium |
| ≥ 2500g | High |

This demonstrates the use of the SQL `CASE` statement for data segmentation.

---

## 7. Total Inventory Weight by Category

```sql
SELECT
    category,
    SUM(weightInGms * availableQuantity) / 1000.0
        AS category_weight_kg
FROM zepto
GROUP BY category
ORDER BY category_weight_kg DESC;
```

### Business Insight

This query calculates the total physical inventory weight of each category.

It can be useful for:

- Warehouse planning
- Logistics
- Storage allocation
- Inventory management
